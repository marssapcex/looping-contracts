# Unit-Aware Invariants

Unless stated otherwise, `U(x)` means the raw integer amount of an 18-decimal token and `x` means its human display amount. A local pass is evidence about exact deployed code in the declared model, not about pinned BSC state. Dust-only rounding is out of scope.

| ID | Invariant and units | Local evidence | Mainnet status |
|---|---|---|---|
| INV-01 — LP principal | For a normal, non-fee LP token, a same-block `deposit(pid,x)` then `withdraw(pid,x)` yields `ΔuserLP=0`, `Δuser.amount=-x+x=0`, and decreases `pool.allocPoint` back to its prior raw value. | `testFuzz_deposit_withdraw_principal`; 1,000 runs per seed, eight seeds (`run.log:43` and corresponding later seeds). | Not fork-verified. |
| INV-02 — Duplicate claims | Repeating a pid within `claim([pid,...])` must not mint twice: after the first occurrence, `user.amount*accRewardPerShare/1e12-user.rewardDebt=0` raw EPS. | `test_duplicate_claim_does_not_double_mint` passes (`run.log:62`). | Not fork-verified. |
| INV-03 — Emission integral | Between schedule changes, pool reward is `duration_seconds * rewardsPerSecond_raw_EPS/s * allocPoint_pid/totalAllocPoint`; with one non-fixed pool its share is 80%, while pid 0 receives 20%. A schedule transition must not retroactively apply the old rate to later intervals. | On-time control produces 120,000 model EPS gross and 60,000 after exit (`run.log:44-46`). Delayed path violates the transition invariant (`run.log:48-60`) → LEAD-001. | Screenshot displays zero current rate, but historical/live state is unverified. |
| INV-04 — MFD supply conservation | `MultiFeeDistribution.totalSupply` (raw EPS accounting units) equals the sum of users' `total = unlocked + locked + earned`; `lockedSupply` equals the sum of users' `locked`. Neither is the EPS ERC-20 global supply. | Stake/exit/lock tests pass; exact expired-lock principal test at `run.log:63`. | Screenshot supplies are unverified by Anvil. |
| INV-05 — Unlocked withdrawal | Withdrawing `x` solely from unlocked EPS transfers exactly `U(x)` to `msg.sender` and reduces both user total and staker total supply by `U(x)`; no penalty applies. | Covered by source review and principal/exit tests. | No pinned call. |
| INV-06 — Early earned exit | If all exited earnings are unexpired, `penalty=earned/2`, `amount=unlocked+earned-penalty`, and staker supply decreases by `amount+penalty` raw EPS. | Delayed PoC: gross 200,000 model EPS, actual withdrawal 100,000 (`run.log:53-59`). Control: gross 120,000, withdrawal 60,000 (`run.log:44-46`). | Model only; EPS USD value unmeasured. |
| INV-07 — Expired locks | `withdrawExpiredLocks` can debit only `msg.sender`, only expired entries, and transfers the summed raw EPS amount once while reducing total and locked supply equally. | `test_expired_lock_principal_conserved` passes (`run.log:63`). | No pinned call. |
| INV-08 — Reward funding | For each reward token, cumulative paid/claimable rewards cannot exceed rewards funded plus penalties accounted by `_notifyReward`, apart from out-of-scope integer truncation. Staking-token rewards use locked balances/supply; other reward tokens use total balances/supply. | On-time control, duplicate-claim test, and STATE0 fuzz; no over-funding except the schedule-ordering LEAD. | Reward balances/rates not read from BSC. |
| INV-09 — Mint authorization | Only an address with `minters[msg.sender]` can call MFD `mint`; only the EPS token's current `minter` can mint/burn the supplied Vyper token. | Unauthorized MFD mint reverts (`run.log:64`); screenshot shows EPS minter is MFD. | Minter linkage not Anvil-verified. |
| INV-10 — Proportional Curve withdrawal | For LP burn `a` and total LP supply `S`, each coin payout is `balances[i]*(a-1)/S` in that coin's raw units; LP supply decreases exactly `a`, and each pool balance decreases by its payout. | Exact Vyper test: cost `100000000000000000000000` raw LP and payout `99999999999999999999999` raw units of each model coin (`run.log:33-37`). | Local mock 18/18-decimal pool only. |
| INV-11 — Quote/execution consistency | With unchanged state, `exchange(i,j,dx,quoted)` returns `get_dy(i,j,dx)`; input decreases by `dx` and output increases by `dy` in the respective coin units. | Exact Vyper test and 8×1,000 fuzz runs; canonical `dx=1000e18`, `dy=999.494929353142191340e18` (`run.log:22,27-30`). | Not a mainnet price claim. |
| INV-12 — Callback atomicity | `exchange`, `exchange_underlying`, `exchange_extended`, and liquidity mutations sharing `@nonreentrant('lock')` must reject nested calls. A callback must supply exactly `dx` input before the outer output transfer. | Nested callback exchange rejected (`run.log:23-25`). | Local exact runtime; deployed storage not read. |
| INV-13 — One-time initialization | CryptoSwap `initialize` requires `mid_fee==0`; a second initialization must revert, preserving factory, token, coins, and parameters. | Exact Vyper reinitialization reverts (`run.log:32`). | Proxy initialization not archive-verified. |
| INV-14 — Oracle/allocation units | USD oracle index 0 is fixed to `100000000` (1e8); each non-USD answer is interpreted in the same 1e8 scale and multiplies raw LP allocation points. A negative answer must not silently become a valid price. | Source review at `contracts/LpTokenStaker.sol:136-156`; no oracle is mocked as mainnet evidence. | Oracle addresses, decimals, freshness, and current answers are unknown without RPC. |

## Campaign coverage

`evidence/campaign.csv` contains 2,880 rows: 10 extreme states × 9 drain strategies × 4 capital tiers × 8 seeds. A–C execute 2,160 local arithmetic cases; D contributes 720 explicit skips because protocol-wide TVL was not measured at ≥ `$1e9`. There are 168 local stale-schedule counterexamples (`evidence/campaign-run.log:6-11`). Canonical `S0-T0-A-seed0` is replayed with real EVM transactions by the named Foundry PoC, not merely by the arithmetic script (`run.log:48-60`).

Capital tiers are raw 18-decimal model LP amounts: A=`1`, B=`1,000,000`, C=`1,000,000,000,000`. The model does not assign them a USD value. Tier D is not run and must not be inferred from the screenshot portfolio totals.
